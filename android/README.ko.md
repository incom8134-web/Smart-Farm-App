# AI 스마트팜 – 안드로이드 앱 (MIT App Inventor V11)

[English](README.md) | **한국어**

- [Ai_Smart_Farm_V11.apk](Ai_Smart_Farm_V11.apk): 안드로이드 설치 파일
- [Ai_Smart_Farm_V11.aia](Ai_Smart_Farm_V11.aia): 편집 가능한 MIT App Inventor 소스

V11은 프로젝트 버전 이름이며, 앱 안에 표시되는 버전은 1.3입니다.
수업 전에 휴대폰과 실제 보드로 앱을 시험하세요.

## 설치

안드로이드 휴대폰에 APK를 설치합니다. 안드로이드가 물어보면 이 출처의 설치를 허용하세요.
안드로이드 블루투스 설정에서 HC-06을 페어링하고, 앱이 요청하면 '근처 기기 / 블루투스' 권한을 허용합니다.

## 편집 및 다시 빌드

1. <https://ai2.appinventor.mit.edu/>에 로그인합니다.
2. **Projects → Import project (.aia) from my computer**를 선택하고 V11 파일을 고릅니다.
   같은 이름의 온라인 프로젝트가 있으면 먼저 백업하세요.
3. Designer와 Blocks를 확인한 뒤 **Build → Android App (.apk)**를 선택합니다.
4. 새 APK를 설치합니다. AIA를 수정해도 이미 설치된 앱은 바뀌지 않습니다.
   서명 키가 다르면 기존 앱을 먼저 삭제하세요.

## 펌웨어와 카메라

보드 프로그램은 [../firmware](../firmware)에 있습니다. 버전, 라이브러리, ESP32 먼저 / 나노 나중 업로드 순서는
[펌웨어 안내](../firmware/README.ko.md)를 참고하세요.

휴대폰과 ESP32-CAM을 같은 공유기에 연결하고, ESP32가 시작할 때 한 번 출력하는 카메라 IP를 앱에 입력합니다.
카메라(Wi-Fi)와 HC-06(블루투스)은 서로 다른 연결입니다.

## 휴대폰 및 보드 점검표

1. 새로 설치: 블루투스 권한을 거부, 재시도, 허용해 보고 블루투스 끄기/켜기를 시험합니다.
2. HC-06을 페어링하고 연결합니다. '알 수 없음' 상태와 2초마다 들어오는 새 센서 값을 확인합니다.
3. ON/OFF 명령을 하나씩 보냅니다. 스위치가 이미 꺼져 보여도 OFF를 보내 봅니다.
   나노 LCD와 실제 출력을 확인합니다.
4. 연결을 끊었다 다시 연결하고 나노 데이터를 중단해 봅니다. 출력이 실제로 꺼진 것처럼 표시되면 안 되고,
   오래된 값이 새 값으로 표시되면 안 됩니다.
5. DHT11을 뽑아 봅니다. 온도/습도는 ERR로 표시되고 아날로그 값은 계속 갱신되어야 합니다.
6. 테마와 언어를 바꿔 봅니다. 현재 값과 명령 상태가 유지되어야 합니다.
7. 잘못된 카메라 IP와 올바른 IP, 실시간 영상, 카메라 화면 나갔다 다시 들어오기를 시험합니다.
8. PCB의 DIP 경로와 전원 정격을 확인하고, ESP32를 다시 업로드할 수 있는지 확인합니다.

**수동 제어 안전:** 명령을 보냈다고 하드웨어가 확인한 것은 아닙니다. 연결을 끊거나 앱을 닫아도
동작 중인 펌프, 팬, 조명은 멈추지 않습니다. OFF를 보내고 실제로 멈췄는지 확인하세요. 펌프는 물에 잠긴 상태로 두세요.
저수위나 연결 끊김 시 자동 차단 기능은 없습니다. DIP 스위치를 바꾸기 전에는 USB와 외부 전원을 **모두** 분리하고,
스위치를 전부 ON으로 하지 마세요.
